## Grade 9 data sources

- [Official SNC1W science curriculum PDF](https://assets-us-01.kc-usercontent.com/fbd574c4-da36-0066-a0c5-849ffb2de96e/a393c5f1-4619-4c34-877a-c22321d01e18/The%20Ontario%20Curriculum%20-%20Science_Grade%209_De-streamed%20Course_2022.pdf): authoritative 2022 expectations. D2.3 covers circuit components, quantities and units; D2.4–D2.5 address relationships and calculations; D2.6 includes constructing and comparing series and parallel circuits. Preserve expectation wording and version separately from interpretations.
- [Ontario MTH1W publication record](https://www.publications.gov.on.ca/CL32215): identifies the 2021 Grade 9 de-streamed mathematics curriculum. Verify the applicable version before importing any course.
- [TVO Learn SNC1W](https://tvolearn.com/products/snc1w-science): Ontario course resources including electricity, electric circuits, energy conversions, and efficiency. Direct lesson links are useful; provider units need not match teacher units.
- [EQAO Grade 9 mathematics](https://www.eqao.com/the-assessments/grade-9-math/): released questions, mappings, sample assessments, formula sheets, and some provincial response statistics. Suitable reference for evaluation design; bulk reuse rights remain to be established.
- [OpenStax K–12](https://openstax.org/k12/): supplementary texts requiring topic, reading-level, and Ontario alignment checks.
- Student-supplied tests, marked work, rubrics, course outlines, handouts, notes, calendars, and photos: private classroom context, subject to authorized access and review. Prefer question-level evidence over an aggregate course mark.
- Original LearnPilot attempts: structured answers, assistance, retries, explanations, and reassessment outcomes. Generated items require review before becoming assessment evidence.

A supported public Ontario curriculum API was not verified. Start with a small reviewed import. [Google Classroom coursework documentation](https://developers.google.com/workspace/classroom/guides/manage-coursework) describes role-dependent submission access and notes that submission permission does not imply attachment permission. School integrations are not a prerequisite for the pilot.

## Rights and privacy references

The following summarize research, not blanket permissions for every proposed use. Preserve exact resource and licence versions; revisit terms before implementation or commercialization.

- [Ontario copyright](https://www.ontario.ca/page/copyright-information): general terms permit attributed, unchanged reproduction for noncommercial purposes; other uses can require licensing. Keep authoritative wording distinct from summaries.
- [TVO Learn terms](https://tvolearn.com/pages/terms-of-use): specified personal, informational, noncommercial uses do not establish permission for a redistributed AI content library.
- [PhET licensing](https://phet.colorado.edu/en/licensing): current regular HTML simulations use CC BY-NC 4.0; commercial licensing and instrumented PhET-iO capabilities are separate considerations.
- [OpenStax licensing](https://help.openstax.org/s/article/Licensing-information-of-OpenStax-textbooks): current guidance describes CC BY-NC-SA. Check the exact title/version and any content exceptions.
- [CK-12 materials licence](https://help.ck12.org/hc/en-us/articles/50990257420955-CK-12-Curriculum-Materials-License): restricts automated derivative creation and specified AI/ML uses. Exclude CK-12 from AI ingestion/generation unless permission for the intended use is established.
- [YouTube embedding guidance](https://support.google.com/youtube/answer/171780?hl=en): explains embedding restrictions, privacy-enhanced mode, and child-directed-site requirements. Linking and embedding are separate implementation choices.
- [Canadian privacy guidance on consent](https://www.priv.gc.ca/en/privacy-topics/privacy-laws-in-canada/the-personal-information-protection-and-electronic-documents-act-pipeda/p_principle/principles/p_consent/?wbdisable=true): youth consent processes should consider maturity; determine applicable obligations for the actual deployment context.

Default pilot policy: curate and link to external resources; create original practice with checked answers; import private classroom material only under appropriate authorization. Do not assume permission to download, transcribe, transform, or redistribute a resource because it is free to view.
